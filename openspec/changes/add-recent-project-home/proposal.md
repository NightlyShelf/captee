## Why

People need fast access to projects they used before. The home screen will show a small, clear recent-project panel instead of making people browse for every project. Pinned projects stay first, while recent projects remain easy to open, remove from the list, or safely delete from disk. Follow-up fixes make project actions clearer and keep the selected Typst file and preview in sync. Preview work files stay hidden from the project tree, and dialog buttons stay compact.
